# Tutorial



## 1\. Install the required packages



> install.packages("sf")

> install.packages("ggplot2")



## 2\. Define plane atoms



Optimise the molecular geometry before running the script. Identify the atoms that will define the reference plane for the Boolean unit calculation (Figure 1). 



Figure 1. Optimised geometry of 1-octyl-3-methylimidazolium (CID 2734224), generated using the MMFF94s molecular mechanics force field in Avogrado, showing atom labels. 



In this example, the reference plane is defined using the atoms of the imidazolium ring, i.e., atoms N1, N2, C8, C9, and C11. 

Export the optimised strcutres as an XYZ cordinate file (the file must be in .txt format). Open the coordinate file and identify the corresponding indices of the plane atoms. In this case, the indices correspond to 1,2,10,11,13. Therefore, the variable plane\_atoms should be defined as:



> plane\_atoms <- c(1,2,10,11,13)





## 3\. Define specimen name



The specimen name must be defined before running the scrip. 



> specimen\_name <- c("1-octyl-3-methylimidazolium")





## 4\. Run the script



Run the script. A file selection window will open automatically.

Selecte the coordinate file (data.txt) that contains the optimised structure. 



The script will import coordinates, fit a least-squares plane through the selected atoms, project atomic vand der Waals radii onto that plane, calculate the oveerlap corrected Boolean union area and, generate a projection of the van der Waals footprint.



The output image will be saved automatically in the same folder as the selected coordiante file (Figure 2).





Figure 2. Example projected van der Waals footprint generated by the script.
